# toggleminds.com

The Toggle Minds family site — a static site published with GitHub Pages.

- `index.html` — the landing page (PhoneMail, ToggleMail, Narada)
- `togglemail/` — the ToggleMail product site; installer links point to GitHub Releases
- `CNAME` — custom domain (toggleminds.com)

Projects: [PhoneMail](https://phonemail.net/) · [ToggleMail](https://github.com/ShankarOnline/togglemail) · [Narada](https://github.com/ShankarOnline/navsuite)
